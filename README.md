# 水溶液計算コンソールアプリケーション

TypeScriptで構築された、水溶液の各種濃度計算および希釈計算を行えるインタラクティブなコンソール（CLI）アプリケーションです。

## 機能

1. **質量パーセント濃度計算 (`%`)**
   - 溶質の質量 (g) と溶媒 (水) の質量 (g) から質量パーセント濃度を算出します。
2. **モル濃度計算 (`mol/L`)**
   - 溶質の質量 (g)、モル質量 (g/mol)、および溶液の体積 (mL) からモル濃度を算出します。
3. **希釈計算 (加水量算出)**
   - 元の濃度・液量と目標濃度から、必要な加水量 (mL) および希釈後の全量を算出します。

## 動作環境

- **Node.js**: v18.0.0 以上推奨 (v22系対応)
- **npm**: v9.0.0 以上
